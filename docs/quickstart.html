Quick Start

Get ton-payout-engine running locally or in Docker in under 5 minutes.

Prerequisites

  • Java 17+
  • Maven 3.8+ (for building from source)
  • A Highload Wallet v2 address and its Ed25519 key file (32 raw bytes, hex, base64, or mnemonic)
  • A TON Center API key

Option A — Run the fat-JAR

1 Download

Grab the latest fat-JAR from the Downloads page or directly from GitHub Releases:

wget https://github.com/SparkyOfficial-ops/ton-payout-engine/releases/download/v__VERSION__/ton-payout-engine-__VERSION__-fat.jar

2 Create the environment file

Never commit secrets. Copy .env.example and fill in your values. 
cp .env.example .env
# Edit .env:
WALLET_ADDRESS=EQxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WALLET_KEY_PATH=/path/to/wallet.key
PAYOUT_API_KEY=your-secret-api-key
TON_API_KEY=your-toncenter-key
PAYOUT_DB_PATH=data/payout.db

3 Run

source .env   # or export vars manually
java -jar ton-payout-engine-__VERSION__-fat.jar

The engine starts an HTTP server on port 8080 (override with SERVER_PORT).

Option B — Docker

1 Pull from GHCR

# by version tag (recommended)
docker pull ghcr.io/sparkyofficial-ops/ton-payout-engine:v__VERSION__

# by commit SHA (matches what GitHub Actions published)
docker pull ghcr.io/sparkyofficial-ops/ton-payout-engine:f394391

# latest stable
docker pull ghcr.io/sparkyofficial-ops/ton-payout-engine:latest

2 Run with a secrets volume

docker run -d \
  --name ton-payout \
  -p 8080:8080 \
  -e WALLET_ADDRESS="EQxxx..." \
  -e WALLET_KEY_PATH="/secrets/wallet.key" \
  -e PAYOUT_API_KEY="your-api-key" \
  -e TON_API_KEY="your-toncenter-key" \
  -v /srv/payout/data:/data \
  -v /srv/payout/secrets:/secrets:ro \
  ghcr.io/sparkyofficial-ops/ton-payout-engine:v__VERSION__

3 Health check

curl http://localhost:8080/health
# 200 OK  →  {"status":"UP"}

Option C — Build from source

1 Clone both repos

git clone https://github.com/SparkyOfficial-ops/cton-sdk.git      cton-sdk-main
git clone https://github.com/SparkyOfficial-ops/ton-payout-engine.git

2 Install the SDK into local Maven repo

mvn -f cton-sdk-main/pom.xml install -DskipTests

3 Build the engine

cd ton-payout-engine
mvn clean package

The fat-JAR lands at target/ton-payout-engine-__VERSION__-SNAPSHOT.jar.

Your first payout

curl -s -X POST http://localhost:8080/api/v1/payout \
  -H "X-Api-Key: your-api-key" \
  -H "X-Idempotency-Key: test-001" \
  -H "Content-Type: application/json" \
  -d '{
    "transfers": [
      {"to": "EQAbc...", "amount": "1.5",  "comment": "alice"},
      {"to": "EQDef...", "amount": "0.5",  "comment": "bob"}
    ]
  }'

Response:

{
  "batchId": "7f3a2c1e-...",
  "status": "queued"
}

Poll the status:

curl -s http://localhost:8080/api/v1/status/7f3a2c1e-... \
  -H "X-Api-Key: your-api-key"
